# LLM의 구성

- LLM의 기초적인 원리 => 다음 단어를 예측하는 것
- 크게 토크나이저와 모델(트랜스포머)로 구성됨
  - 토크나이저의 경우 주로 통계적 기법으로 학습시킴.
  - 모델 학습의 경우 사전 학습과 사후 학습으로 나뉨.
  - 사전 학습을 통해 다음 텍스트를 예측할 수 있는 베이스 모델을 만듦.
  - 베이스 모델을 사후 학습시켜 모델이 주어진 질문에 사고하고 답을 내놓을 수 있도록 만듬.
  - 사후학습 중 SFT는 질의응답 체계를 만들고, 강화학습은 답변의 퀄리티를 높임.

## 트랜스포머

- 어텐션
  - 간단히 말해서 ‘소프트 딕셔너리’
  - 하드 딕셔너리는 쿼리와 일치하는 키의 값을 출력하지만, 소프트 딕셔너리는 모든 딕셔너리 안의 모든 원소를 검토해 출력을 결정함.
  - 유사도를 계산한 뒤, 소프트맥스 함수를 적용해 정규화해 가중치를 얻고, 각 밸류에 가중치를 곱해서 최종 출력을 구함.
- 트랜스포머의 기본 구조
  - 토크나이저가 텍스트를 토큰 ID 열로 변환
  - 토큰을 임베딩 과정을 통해 벡터로 변환
  - 트랜스포머 블록(어텐션 + FFN)을 통해 입력 토큰의 갯수와 동일한 갯수의 확률 분포를 생성
  - 각 위치에서 출력되는 확률 분포는 그 위치 다음에 올 토큰의 예측을 나타냄.
- 어텐션을 통해 특정 토큰의 임베딩 벡터를 주변 문맥에 맞게 재조정할 수 있음.
- 어텐션은 자체적으로 토큰의 위치 정보를 다룰 수 없음. 언어에서는 어순이 중요하기 때문에, 임베딩 벡터에 위치 인코딩을 추가하여 이 문제를 해결함.
- 트랜스포머를 학습할 때 입력 토큰열을 한 칸씩 왼쪽으로 옮긴 결과를 정답 레이블로 사용함으로써 한 번에 대량으로 데이터를 학습시킬 수 있음.
  - 그러나 이렇게 구성할 경우 학습 시점에 어텐션이 정답에 해당하는 토큰까지 참조해서, 학습이 제대로 이루어지지 않는 문제가 있음. 이 문제를 해결하기 위해 각 토큰이 자기 자신과 그보다 앞선 토큰의 정보만 참조하게 만드는 ‘어텐션 마스크’ 기법을 사용하여 해결함.
- 멀티헤드 어텐션이란 여러 어텐션 헤드를 병렬적으로 실행시켜, 입력을 다양한 관점에서 분석하고 학습할 수 있게 만드는 기법.

## 학습

- 사전 학습
  - 대량의 텍스트 데이터를 사용해 ‘다음 토큰을 예측하는’ 능력을 모델에 학습시키는 것
  - 학습 데이터와 별개로 검증 데이터를 준비하여 학습 중인 모델의 성능을 평가하는 것이 일반적임.
- 사전 학습이 완료된 모델은 프롬프트를 토크나이저로 토큰 ID열로 변환한 뒤, 트랜스포머를 통해 각 토큰 위치의 확률 분포를 구하고, 가장 마지막 위치의 확률 분포를 골라 해당 토큰을 토큰 ID열의 끝에 추가하는 방식으로 텍스트를 생성함.
- 확률 분포에서 토큰을 선택하는 것을 샘플링이라고 하고, 주로 온도 파라미터를 사용함. 온도가 높을수록 확률 분포가 고르게 퍼짐.
- 온도 파라미터를 사용하는 방법 외에도 확률이 높은 상위 k개의 토큰으로 후보를 한정하는 Top-k 샘플링, 누적 확률이 p에 도달할 때까지의 토큰으로 후보를 한정하는 Top-p 샘플링 등이 자주 사용됨.
- SFT (지도 파인튜닝)
  - 사전 학습이 끝난 모델은 이어지는 텍스트를 생성할 뿐, 질문에 답하거나 지시에 맞는 응답을 반환하지 않기 때문에, SFT를 통해 대화형 패턴을 학습시킴.
- 강화 학습
  - 강화학습의 목표는 모델이 최적의 보상을 획득할 수 있도록 학습시키는 것이고, 조금 더 구체적으로는 최적의 보상을 획득할 수 있는 파라미터 세타 값을 찾는 것임.
  - 대표적인 방법으로 정책 경사법이 있음.
